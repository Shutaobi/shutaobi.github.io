# Computational code for Geometric Realization

Companion computations for **Geometric Realization**, Shutao Bi, October 2026.
[Manuscript](https://shutaobi.github.io/thesis/Geometric_Realization.pdf).

This package contains the two computational programs cited in the paper, their
required certificate input, and dependency versions. It excludes the paper,
editorial records, historical backups, build files, logs, and generated reports.
The Python programs are copied unchanged from the current manuscript directory.

## Connection to the paper

- **Length-five auxiliary algebra (Lemma 3.4):**
  `nr_B5_generic_certificate.py` performs exact rational noncommutative
  Gröbner-basis computations for the weighted algebra
  `B = Q<x,y>/(x^4, y^2 + yx^2 + x^2y + xyx)`, with weights `wt(x,y)=(1,2)`
  and central element `S = yxy + y^2x + yx^3`. It checks the dimensions
  `dim B/(S)=40` and `dim B/(S-1)=25`, explicit 5-by-5 matrices, regular trace
  determinant `298023223876953125 = 5^25`, centre dimension one, and generic
  rank 25 from the weighted Hilbert series.
- **Zero-quartic rational certificate (Lemma 4.9 and Section 6):**
  `verify_zero_quartic.py` reads `zero_quartic_certificate.json` and verifies
  the five original-ideal identities, all 17 overlap/inclusion ambiguities,
  all 11 critical syzygy decompositions (31 summands), and the 10-state
  automaton identities giving `H(t) = 1/((1-t)^2(1-t^3))`.

These are the finite exact calculations used by the manuscript. The formal
lifting, growth estimates, and geometric arguments are supplied in the paper.

## Files

```text
requirements.txt
tools/numerical_realisation_certificates/
  nr_B5_generic_certificate.py
  verify_zero_quartic.py
  zero_quartic_certificate.json
```

The JSON file is essential input to the zero-quartic verifier, not a run log.
Keep it beside `verify_zero_quartic.py`. The B5 JSON is generated by its program
and is not bundled.

## Run

Use **Python 3.10 or later**. From this package's root directory, the zero-quartic
verifier needs only the Python standard library:

```sh
python3 tools/numerical_realisation_certificates/verify_zero_quartic.py
```

A successful run prints `PASS` for the ideal, ambiguity, syzygy, and Hilbert-series
checks. To run the length-five calculation, install the pinned dependencies
(`sympy==1.14.0`, `mpmath==1.3.0`), preferably in a virtual environment:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python tools/numerical_realisation_certificates/nr_B5_generic_certificate.py --output output/nr_B5_generic_certificate.json
```

On Windows, activate the environment with `.venv\Scripts\activate` instead.
The B5 program prints its dimensions, matrices, trace determinant, centre
dimension, Hilbert series, and generic rank, then writes its certificate to
`output/`. The directory is created automatically. Run both programs without
Python's `-O`/`-OO` options, since their checks use assertions.
